## 踩坑：刷新一次弹一次

上线后立刻发现一个烦人的问题：**每刷新一次页面，就要重新验证一次**。我自己写博客调样式的时候，刷一下就卡一道验证，心态爆炸。

解决办法很简单：验证通过后，把状态写进 `sessionStorage`。同一标签页里再刷新，直接跳过验证、正常放行；只有关掉标签页重新打开才需要再验证一次。

if (!sessionStorage.getItem('turnstile-passed')) {
  // 弹验证，通过后写入标记
  turnstile.render(...)
} else {
  hideLoading();  // 已验证过，直接跳过
}
