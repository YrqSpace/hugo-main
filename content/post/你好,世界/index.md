## 😄我人生中第一个博客,兴奋!

2026 年 9 月 19 日，这个站有了第一篇文章。

没有仪式，也没有倒计时——就是把 Hugo 跑通、本地地址能打开、文章卡片点得进去，然后顺手发了一条。发出来那一刻还是挺爽的，毕竟这是"我自己的网站"，而不是某个平台上的一个主页。

## 这个站是怎么搭的

没什么技术含量，结构就四样东西：

| 部分 | 用的什么 |
| --- | --- |
| 生成器 | Hugo（静态站点，本地生成 HTML 再发布） |
| 主题 | Stack |
| 托管 | GitHub Pages |
| 域名 | yrqspace.github.io |

选这套的理由很单纯：**纯静态、没有后端、不花钱**。写文章就是往 `content/post/` 里扔一个文件夹，`hugo` 跑一遍，推上去，站就更新了。不用管数据库，不用管服务器，也不用担心哪天服务挂了。

代价也摆在那儿——没有后端，就没有真正意义上的登录、评论和服务端校验。后来折腾人机验证、友链申请，根子都在这上面：所有逻辑只能在前端跑，能做的事天然有限。

## 为什么叫这个名字

字面意思：**爱玩 Windows 11 的我**。平时折腾的就是这些东西，顺手拿来当站名，也不打算换个更"高级"的。

所以这个博客的底色很清楚——**记录折腾**。不是教程站，也不是资讯站，就是自己一路踩坑、填坑的流水账。写下来主要是怕自己忘，次要原因是想着万一有人搜到同样的问题，能少走两步。

## 打算写什么

目前就三个方向：

1. **建站折腾**：Hugo、改主题样式、部署流程、各种莫名其妙的小问题
2. **收录与 SEO**：一个纯静态博客怎么让搜索引擎看见
3. **独立博客那点事**：友链、互链、给开源项目提 PR

更新频率不承诺。有话就写，没话就空着——这大概是独立博客最后一点自由。

## 现在的样子

写这篇的时候，站里陆续攒了几篇：Bing 收录的两次折腾、Uptime 状态页、Cloudflare Turnstile 人机验证、友链页 DIY、第一次给别人的项目提 PR。

都不是什么大事，但每一篇后面基本都搭进去一个晚上。这也是我坚持写下来的原因：过程比结论更值得记。

**你好，世界。** 以后慢慢聊。
